# Источник варианта

Вариант собран по официальному проекту демонстрационного варианта ЕГЭ 2027 года по информатике ФГБНУ «ФИПИ».

- исходный архив: `inf_11_2027.zip`;
- документ: `ИНФ-11 ЕГЭ 2027 ДЕМО.pdf`;
- дата документа: 21.08.2026;
- дата публикации архива: 22.09.2026;
- официальный адрес: https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2027/inf_11_2027.zip

Для позиций 14 и 25, где в демонстрационном документе приведено несколько альтернатив, в вариант включён первый пример. Числовые данные, условия, приложения и ключи взяты из официального комплекта.
