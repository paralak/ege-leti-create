# Формат варианта v2

Каждый вариант хранится в отдельной директории `variant`:

```text
variant/
├── manifest.xml
├── tasks.xml
├── answer_key.xml
├── answers.xml
└── files/
```

- `manifest.xml` содержит ID, название, предмет, длительность и количество заданий.
- `tasks.xml` содержит условия без правильных ответов. Корневой `variant_id` должен совпадать с ID манифеста.
- `answer_key.xml` содержит только правильные ответы и имеет `kind="key"`.
- `answers.xml` создаётся программой тестирования и имеет `kind="student"`.
- `files` содержит приложения, перечисленные в `attachments` соответствующего задания.

Перед передачей варианта ученику удаляется только `answer_key.xml`. Файлы `manifest.xml`, `tasks.xml` и директория `files` должны оставаться вместе.

Номер задания используется для отображения. Связывание заданий, ключа и ответов выполняется только по стабильному `task_id`.
