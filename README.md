# ЕГЭ ЛЭТИ — конструктор вариантов

Локальная программа для создания и редактирования вариантов ЕГЭ по информатике. Проект запускается в оболочке [phpDesktop Chrome](https://github.com/cztomczak/phpdesktop).

## Установка

1. Скачайте и распакуйте phpDesktop Chrome для Windows.
2. Скопируйте `settings.json` и папку `www` из этого репозитория в каталог phpDesktop с заменой файлов.
3. Запустите `phpdesktop-chrome.exe`.

Программа открывает конструктор из `www`. Задания, ответы и приложенные файлы сохраняются в `www/variant`, поэтому у приложения должны быть права на запись в эту папку.

## Результаты

- `variant/tasks.xml` — вариант без правильных ответов;
- `variant/tasks_with_answers.xml` — вариант с правильными ответами;
- остальные файлы в `variant` — изображения и приложения к заданиям.

Перед передачей папки `variant` ученику вынесите из неё `tasks_with_answers.xml`. Этот файл используется только программой проверки результатов.
