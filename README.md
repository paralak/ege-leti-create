# ЕГЭ ЛЭТИ — конструктор вариантов

Локальная программа для создания и редактирования вариантов ЕГЭ по информатике. Проект запускается в оболочке [phpDesktop Chrome](https://github.com/cztomczak/phpdesktop).

## Установка

1. Скачайте и распакуйте phpDesktop Chrome для Windows.
2. Скопируйте `settings.json` и папку `www` из этого репозитория в каталог phpDesktop с заменой файлов.
3. Запустите `phpdesktop-chrome.exe`.

Программа открывает конструктор из `www`. Задания, ответы и приложенные файлы сохраняются в `www/variant`, поэтому у приложения должны быть права на запись в эту папку.

## Результаты

- `variant/manifest.xml` — метаданные и версия формата;
- `variant/tasks.xml` — условия заданий без правильных ответов;
- `variant/answer_key.xml` — отдельный ключ правильных ответов;
- `variant/files` — изображения и приложения к заданиям.

Все выбранные при сохранении задания файлы автоматически добавляются к его вложениям, даже если ссылка на файл не была вставлена в текст.

Перед передачей папки `variant` ученику вынесите из неё `answer_key.xml`. Этот файл используется только программой проверки результатов.

Полное описание структуры приведено в [VARIANT_FORMAT.md](VARIANT_FORMAT.md).
